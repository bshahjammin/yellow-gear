🌱 What is BIOGLOW?

BIOGLOW is the 2026-2027 biodiversity-themed FIRST LEGO League season. Teams explore how living organisms, ecosystems, nature, technology, and people are connected. Challenge teams build and program an autonomous SPIKE Prime robot, solve Robot Game missions, and develop an Innovation Project related to biodiversity.

⚙️ Yellow StormGears Ways of Working

Our goal: Learn, build, solve problems, compete as a team, and have fun.

1. Team Rules

  • Be kind and respectful.
  • Everyone participates.
  • Kids do the work; adults guide.
  • Challenge ideas, not people.
  • Mistakes help us learn.
  • Have fun and support the team.

2. Role Rotation

No permanent coder, builder, or presenter. Rotate building, coding, testing, attachments, research, documentation, presenting, and robot operation every 1-2 meetings.

3. Working Together

  • Start on time.
  • One person speaks at a time.
  • Ask before changing someone else's work.
  • Share robot, computer, and LEGO time fairly.
  • Ask two teammates before the coach.

4. Disagreements

  1. Listen to both ideas.
  2. Build or test when possible.
  3. Let results help decide.
  4. If needed, vote or ask the coach to facilitate.

5. End Every Meeting

What did we accomplish? What did not work? What comes next? Who owns each next step? Clean up before leaving.

6. At Competitions

Respect judges, referees, volunteers, and teams. No blaming. Cheer for everyone. Be honest about our work. Behavior matters as much as score.

7. Parent Guidelines

Help kids arrive on time, encourage without solving, let kids explain their work, keep scores in perspective, and share concerns privately with coaches.

8. Safety & Respect

Everyone should feel safe and welcome. No bullying, harassment, inappropriate language, aggression, or intentionally damaging another person's work.

9. Team Promise

We learn together, listen, help each other, respect each other, keep trying, and have fun.

10. FIRST Core Values

Discovery • Innovation • Impact • Inclusion • Teamwork • Fun

⭐ What should we focus on first?

  1. Understand a few missions deeply before trying all 15.
  2. Build a simple, square, repeatable driving base.
  3. Make every child learn basic movement and attachments.
  4. Start Innovation Project research early, not near competition.
  5. Keep an Engineering Notebook record of tests, failures, changes, and decisions.

🏆 Robot Game Scoring

The Robot Game has 15 BIOGLOW missions in a 2.5-minute match. The official Rulebook and software scoresheet define exactly when points count.

Best scoring strategy: reliable points first. A lower-value route that works almost every time is usually more useful than a high-value route that rarely works.

🎯 How to get more points

  • Protect precision tokens by reducing unnecessary robot interruptions.
  • Start with nearby, low-risk missions and combine them into short routes.
  • Use consistent launch positions and alignment jigs.
  • Prefer simple attachments that can do more than one job.
  • Test each route 5-10 times and record its success rate.
  • Only add complexity after the current route is repeatable.
  • Practice the complete 2.5-minute match with two robot operators.

🤖 Robot Design

Build

Rigid driving base, wheels aligned, cables secured, easy-to-change attachments, consistent starting position.

Code

Learn distance, turns, motor control, gyro/sensors, functions/blocks, and how to recover from small errors.

Test

Run the same program repeatedly. Measure success. Change one variable at a time.

Explain

Every child should be able to tell judges what the robot does, why the team chose that design, what failed, and how it improved.

Engineering Design Process

Identify → Design → Create → Iterate → Communicate

Judges care about the thinking and improvement process, not only the finished robot.

💡 Innovation Project

Choose a real problem connected to biodiversity. Research it, understand who is affected, create a solution, get feedback, improve it, and present your story to judges.

1. Identify

Pick one specific, meaningful problem. Avoid topics that are too broad.

2. Research

Use reliable sources and talk to an expert or stakeholder when possible.

3. Design

Brainstorm several ideas, compare them, then choose one.

4. Create

Make a prototype, model, diagram, experiment, app concept, or demonstration.

5. Iterate

Ask for feedback, test assumptions, and improve the solution.

6. Communicate

Explain problem, research, solution, feedback, changes, and impact clearly.

Questions every teammate should answer

  • Why did we choose this problem?
  • What did we learn from research or experts?
  • Who would our solution help?
  • What is new or useful about it?
  • What feedback did we receive?
  • What did we change because of that feedback?

🗓️ 12-Week Team Roadmap

Weeks 1-2Theme, Ways of Working, build mission models, basic driving, explore Project Sparks.
Weeks 3-4Choose early robot missions, learn turning/attachments, shortlist Innovation Project problems.
Weeks 5-6Make several missions reliable, choose the project problem, research and interview experts.
Weeks 7-8Combine missions into routes, build project prototype, collect feedback.
Weeks 9-10Full-match practice, improve project solution, prepare Robot Design explanation.
Week 11Mock judging, timed Robot Game runs, Core Values examples, fix weak areas.
Week 12Competition simulation, pack materials, rest, encourage each other, have fun.

Suggested meeting split

10 min kickoff • 50 min robot • 35 min Innovation Project • 15 min testing/judging practice • 10 min reflection and cleanup.
