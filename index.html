What is BIOGLOW?

BIOGLOW is a biodiversity-inspired FIRST LEGO League season. Teams explore how living things, ecosystems, people, science, and technology are connected, then use engineering and innovation to solve challenges.

⚙️ Our Ways of Working

1. Team Rules
Be kind and respectful. Everyone participates. Kids do the work and adults guide. Challenge ideas, not people. Mistakes help us learn.
2. Rotate Roles
No permanent coder, builder, or presenter. Rotate building, coding, testing, attachments, research, documentation, presenting, and robot operation.
3. Work Together
Start on time, listen while others speak, ask before changing someone else's work, and share robot and computer time fairly.
4. Handle Disagreements
Listen to both ideas, build or test when possible, use results to decide, and vote or ask a coach to facilitate when needed.
5. End Every Meeting
What did we accomplish? What did not work? What comes next? Who owns each next step? Clean up before leaving.
6. At Competitions
Respect judges, referees, volunteers, teammates, and other teams. No blaming. Cheer for others and be honest about our work.
7. Parent Guidelines
Encourage without solving. Let kids explain their work. Keep scores in perspective and share concerns privately with coaches.
8. Safety & Respect
Everyone should feel safe and welcome. No bullying, harassment, aggression, inappropriate language, or damaging someone's work.
9. Team Promise
We learn together, listen, help each other, respect each other, keep trying, and have fun.
10. FIRST Core Values
Discovery • Innovation • Impact • Inclusion • Teamwork • Fun

⭐ What should we focus on first?

  1. Understand a few missions deeply before trying all 15.
  2. Build a simple, square, repeatable driving base.
  3. Make every child learn basic movement and attachments.
  4. Start Innovation Project research early.
  5. Record tests, failures, changes, and decisions in the Engineering Notebook.

Reliable points first

For each robot run ask: Does it work at least most of the time? Can we make it simpler? Can we combine nearby missions? Can multiple kids explain the attachment and code?

The reliability target is team coaching guidance, not an official FIRST rule.

🎯 How to get more points

  • Start with nearby, low-risk missions.
  • Use consistent launch positions and alignment guides.
  • Build simple attachments that can perform more than one job.
  • Test each route repeatedly and record success rate.
  • Combine missions only after each one works reliably.
  • Practice complete 2.5-minute matches with your robot operators.

Mission planning board

Now: Choose 2 to 4 missions that are close to a launch area and easy to repeat.

Next: Combine nearby missions into short routes.

Later: Add harder bonuses only when the current routes are dependable.

Robot Design: what judges want to understand

Judges want to hear the team's engineering story, including decisions, testing, failures, improvements, and what the kids learned.

Build

Rigid base, aligned wheels, secured cables, simple attachments, consistent starting position.

Code

Distance, turns, motor control, sensors, reusable blocks, and error recovery.

Test

Run the same program repeatedly, measure success, and change one variable at a time.

Explain

Every child should be able to explain design choices, code, failures, and improvements.

Engineering Design Process

Identify → Design → Create → Iterate → Communicate

✅ Robot Design Checklist

Innovation Project: solve a real biodiversity problem

Do not start with a cool invention. Start by finding and understanding a real problem, then research, create, get feedback, improve, and communicate.

1. IdentifyChoose one specific biodiversity problem that matters to people, animals, plants, or ecosystems.
2. ResearchUse reliable sources and talk with experts or people affected by the problem.
3. DesignBrainstorm several possible solutions before choosing one.
4. CreateMake a prototype, model, diagram, experiment, app concept, or demonstration.
5. IterateShare it, collect feedback, test assumptions, and improve the idea.
6. CommunicateTell judges the story of the problem, research, solution, feedback, changes, and impact.

Good 4th-grade problem questions

  • What is harming local plants or animals?
  • Where do people and wildlife have trouble sharing space?
  • How can communities help pollinators or habitats?
  • What biodiversity problem do scientists or parks still struggle with?
  • What could kids help improve?

12-Week Season Roadmap

Weeks 1-2Theme, Ways of Working, mission models, field setup, basic driving, Project Sparks.
Weeks 3-4Choose early robot missions, learn turns and attachments, shortlist project problems.
Weeks 5-6Make several missions reliable, select the project problem, research and talk to experts.
Weeks 7-8Combine missions into routes, create a project prototype, collect feedback and improve.
Weeks 9-10Full-match practice, improve the project, prepare Robot Design explanations.
Week 11Mock judging, timed Robot Game runs, Core Values examples, fix weak areas.
Week 12Competition simulation, pack materials, practice calmly, celebrate progress.
Final weeks: avoid major redesigns unless something is truly broken. Reliability and confident explanations often benefit more from practice than a last-minute rebuild.
